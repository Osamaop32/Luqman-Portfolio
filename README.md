# Luqman M Ashraf — 3D Portfolio

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or double-click it in a browser.
4. Keep an internet connection for Google Fonts and the Three.js CDN.

## Before publishing
- Replace the LinkedIn link in the Contact section with your real profile URL (it currently points to linkedin.com).
- The contact form opens the visitor's email app (mailto). For a real inbox form, connect a service like Formspree.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, neon styling and CSS 3D effects
- `script.js` — Three.js particle scene, mobile navigation, reveal effects and card tilt

The background uses Three.js from a CDN, so internet access is needed for that effect. If WebGL is unavailable, the rest of the portfolio still works.
